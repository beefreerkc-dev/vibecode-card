Как отправить открытку в eXpress, чтобы в чате была картинка, а интерактив открывался по клику

1. Опубликуйте оба файла из этой папки на любом хостинге как статический сайт:
   - index.html
   - og-vibecode-beeline.png

   Подойдут: Vercel, Netlify, GitHub Pages, внутренний корпоративный веб-сервер.

2. После публикации откройте index.html и замените все вхождения SITE_URL на реальный публичный адрес папки/сайта.
   Пример:
   SITE_URL -> https://example.com/vibecode-card

3. Отправьте в чат eXpress именно ссылку на страницу, а не HTML-файл.
   В чате должна появиться картинка-превью из og-vibecode-beeline.png.
   По нажатию на карточку/ссылку откроется интерактивная открытка.

Важно:
- Если отправить HTML как файл, мессенджер будет воспринимать его как документ.
- Если отправить PNG как картинку, она откроется сразу, но интерактива не будет.
- Для одновременного эффекта нужна ссылка на страницу + Open Graph картинка.
